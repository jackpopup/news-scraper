# News Curator - Product Requirements Document (PRD)

## 1. 제품 개요

### 1.1 제품명
**News Curator** (가칭)

### 1.2 한 줄 소개
> "내가 원하는 뉴스만, 10분 안에 브리핑 완성"

### 1.3 제품 비전
PR 담당자, 마케터, 경영진, 투자자가 매일 아침 뉴스 스크랩에 쓰는 시간을 획기적으로 줄여주는 **극도로 개인화된 무료 뉴스 큐레이션 서비스**

---

## 2. 타겟 사용자

| 페르소나 | 니즈 | 현재 Pain Point |
|----------|------|-----------------|
| **PR 담당자** | 자사/경쟁사 뉴스 모니터링, 일일 브리핑 작성 | 매일 1-2시간 뉴스 검색, 수작업 정리 |
| **마케터** | 업계 트렌드, 캠페인 레퍼런스 수집 | 여러 사이트 돌아다니며 검색 |
| **경영진** | 핵심 뉴스만 빠르게 파악 | 불필요한 뉴스까지 읽어야 함 |
| **투자자** | 포트폴리오 기업 동향 파악 | 여러 기업 한번에 모니터링 어려움 |

---

## 3. 핵심 가치 제안

### 3.1 vs 기존 서비스 (뉴스럴, 아이서퍼 등)

| 기능 | 기존 서비스 | News Curator |
|------|-------------|--------------|
| **가격** | 무료 제한 → 유료 유도 | **완전 무료** |
| **키워드 수** | 5~10개 제한 | **30개까지** |
| **개인화 설정** | 단순 키워드 매칭 | **세밀한 튜닝 (티어, 보너스, 페널티)** |
| **온보딩** | 키워드 입력만 | **단계별 튜토리얼로 최적 설정 가이드** |
| **결과 편집** | 제한적 | **TOP 10 자유 편집 후 발행** |

### 3.2 핵심 차별점
1. **극도의 개인화**: 단순 키워드가 아닌, 회사 중요도(티어), 맥락 보너스, 노이즈 페널티까지 설정
2. **튜토리얼 온보딩**: 처음 사용자도 5분 안에 "내가 원하는 뉴스"가 나오도록 가이드
3. **완전 무료**: 키워드 제한, 기능 제한 없음

## 4. MVP 기능 명세

### 4.1 기능 목록

#### P0 (Must Have)
| 기능 | 설명 |
|------|------|
| **회원가입/로그인** | 이메일 기반 간편 가입 |
| **온보딩 튜토리얼** | 5단계 설정 가이드 |
| **프로필 생성** | 키워드 30개, 회사 티어, 보너스/페널티 설정 |
| **뉴스 스크래핑** | Google News, Naver News 수집 |
| **TOP 10 자동 선정** | 스코어링 기반 상위 10개 선별 |
| **전체 기사 목록** | 스크래핑된 모든 기사 조회 (페이지네이션) |
| **TOP 10 편집** | 드래그 순서 변경, 추가/삭제 |
| **이메일 발송** | 편집한 브리핑을 이메일로 발송 |

#### P1 (Should Have)
| 기능 | 설명 |
|------|------|
| **AI 요약** | 각 기사 1-2줄 요약 |
| **중복 제거** | 같은 뉴스 여러 매체 보도 시 대표 1개만 |
| **히스토리** | 최근 7일 발송한 기사 중복 방지 |
| **프로필 복수 관리** | 여러 프로필 생성 (예: 자사용, 경쟁사용) |

#### P2 (Nice to Have)
| 기능 | 설명 |
|------|------|
| **슬랙 연동** | 브리핑을 슬랙 채널로 발송 |
| **예약 발송** | 매일 오전 9시 자동 발송 |
| **피드백 학습** | "이 기사 별로" → 다음부터 비슷한 기사 제외 |

### 4.2 온보딩 튜토리얼 Flow

```
[1단계] 기본 정보
├── "어떤 회사에서 일하세요?"
├── 회사명 입력 → AI가 대표자명 자동 검색 (수정 가능)
│   예: "삼성전자" 입력 → "삼성전자 | 이재용" 자동 설정
│   → 검색 시 "삼성전자 OR 이재용"으로 정확한 기사만 수집
└── "어떤 업무를 하세요?" (PR/마케팅/경영/투자)

[2단계] 자사 뉴스 설정
├── "자사 뉴스에서 중요한 키워드는?"
├── 예시 제공: 신제품, 실적, 인사, 파트너십 등
└── 최대 10개 선택/입력

[3단계] 경쟁사 설정
├── "경쟁사는 어디인가요?"
├── **AI 자동 추천**: 자사 입력 시 같은 업종 경쟁사 5개 자동 제안
│   예: "삼성전자" → "LG전자, SK하이닉스, 애플, TSMC, 인텔" 추천
├── 각 경쟁사도 대표자명 자동 매칭 (수정 가능)
├── 티어 설정: 1순위/2순위/그 외
└── 최대 10개

[4단계] 관심 주제
├── "어떤 주제에 관심 있으세요?"
├── 카테고리 선택: AI, ESG, M&A, 마케팅, 채용 등
└── 각 카테고리별 세부 키워드 자동 설정

[5단계] 노이즈 필터
├── "이런 뉴스는 안 봐도 돼요"
├── 예시: 주식, 부고, 인사이동, 광고성 기사
└── 체크박스로 간단 선택

[완료] 샘플 결과 미리보기
├── 지금 설정으로 스크래핑 실행
├── TOP 10 결과 보여주기
├── "마음에 드세요?" → 완료 or 다시 설정
└── 설정 저장
```

## 5. 기술 스택

### 5.1 아키텍처

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Frontend   │────▶│   bkend.ai   │────▶│   Scraper    │
│   (React)    │◀────│   (Backend)  │◀────│   (Python)   │
└──────────────┘     └──────────────┘     └──────────────┘
                            │
                            ▼
                     ┌──────────────┐
                     │   Database   │
                     │  (bkend.ai)  │
                     └──────────────┘
```

### 5.2 기술 선택

| 영역 | 기술 | 이유 |
|------|------|------|
| **Frontend** | React + Vite | 빠른 개발, 컴포넌트 재사용 |
| **Backend** | bkend.ai | 서버리스, 빠른 API 구축 |
| **Scraper** | Python (현재 구현됨) | Google/Naver News 스크래핑 |
| **AI** | OpenAI GPT-4o-mini | 요약, 향후 챗봇 |
| **배포** | Vercel (FE) + Docker (Scraper) | 무료 티어 활용 |

### 11.2 백엔드(bkend.ai) 상세 가이드

#### bkend.ai란?
- 노코드/로우코드 백엔드 서비스
- DB + API를 자동 생성해주는 BaaS (Backend as a Service)
- Firebase나 Supabase와 유사하지만 더 간단

#### 설정 순서

```
1. bkend.ai 가입
   └── https://www.bkend.ai 접속 → 회원가입

2. 새 프로젝트 생성
   └── 프로젝트명: "news-curator"

3. Collections(테이블) 생성
   ├── users: 사용자 정보
   ├── profiles: 뉴스 프로필 설정
   ├── scrape_results: 스크래핑 결과
   └── briefings: 발송 히스토리

4. API 키 발급
   └── 설정 → API Keys → 새 키 생성
   └── .env 파일에 저장:
       BKEND_API_KEY=your-api-key
       BKEND_SERVICE_URL=https://your-project.bkend.io

5. API 테스트 (curl 예시)
   # 데이터 조회
   curl -X GET "https://your-project.bkend.io/users" \
        -H "Authorization: Bearer your-api-key"

   # 데이터 생성
   curl -X POST "https://your-project.bkend.io/users" \
        -H "Authorization: Bearer your-api-key" \
        -H "Content-Type: application/json" \
        -d '{"email": "test@test.com", "name": "테스트"}'
```

### 11.3 인증(OAuth) 상세 가이드

#### 옵션 비교

| 방식 | 난이도 | 장점 | 단점 |
|------|--------|------|------|
| 이메일+비번 | 중 | 심플, 완전 제어 | 비번 관리 부담 |
| Google OAuth | 중 | 가입 간편, 보안↑ | Google 의존 |
| bkend.ai Auth | 하 | 가장 쉬움 | 기능 제한 가능 |

#### Google OAuth 구현 순서 (추천)

```
1. Google Cloud Console 설정
   ├── console.cloud.google.com 접속
   ├── 새 프로젝트 생성
   ├── OAuth 동의 화면 설정
   │   └── 앱 이름, 이메일 등 입력
   └── 사용자 인증 정보 → OAuth 2.0 클라이언트 ID 생성
       └── 승인된 리다이렉트 URI: http://localhost:3000/auth/callback

2. 프론트엔드 설정
   └── @react-oauth/google 패키지 설치
   └── GoogleOAuthProvider로 앱 감싸기
   └── GoogleLogin 컴포넌트 사용

3. 백엔드 처리
   └── Google에서 받은 토큰 검증
   └── 사용자 정보 추출 (이메일, 이름)
   └── DB에 사용자 생성/조회
   └── 자체 JWT 토큰 발급

4. 로그인 상태 유지
   └── JWT를 localStorage에 저장
   └── API 요청 시 Authorization 헤더에 포함
   └── 토큰 만료 시 재로그인 유도
```

#### 간단한 코드 예시

```javascript
// 프론트엔드: 로그인 버튼
import { GoogleLogin } from '@react-oauth/google';

<GoogleLogin
  onSuccess={(response) => {
    // response.credential = Google ID 토큰
    fetch('/api/auth/google', {
      method: 'POST',
      body: JSON.stringify({ token: response.credential })
    });
  }}
/>

// 백엔드: 토큰 검증 (Python)
from google.oauth2 import id_token
from google.auth.transport import requests

def verify_google_token(token):
    info = id_token.verify_oauth2_token(token, requests.Request())
    return {
        'email': info['email'],
        'name': info['name']
    }
```

### 11.4 AI 기능 구현 가이드

#### 회사명 → 대표자명 검색

```python
# OpenAI API 사용
import openai

def get_company_ceo(company_name: str) -> str:
    response = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{
            "role": "user",
            "content": f"{company_name}의 현재 대표이사(CEO) 이름을 한 단어로만 답해줘. 모르면 '없음'이라고 해."
        }],
        max_tokens=20
    )
    return response.choices[0].message.content.strip()

# 사용 예시
ceo = get_company_ceo("삼성전자")  # "이재용"
```

#### 경쟁사 자동 추천

```python
def get_competitors(company_name: str, count: int = 5) -> list:
    response = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{
            "role": "user",
            "content": f"{company_name}의 주요 경쟁사 {count}개를 JSON 배열로 답해줘. 형식: [\"회사1\", \"회사2\", ...]"
        }],
        max_tokens=100
    )
    import json
    return json.loads(response.choices[0].message.content)

# 사용 예시
competitors = get_competitors("삼성전자")  # ["LG전자", "SK하이닉스", ...]
```
