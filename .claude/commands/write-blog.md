# 바이브 코딩 블로그 글 작성

DEVLOG.md와 대화 기록을 바탕으로 bkamp.ai 커뮤니티용 블로그 글을 작성합니다.

## 사용법

```
/write-blog
```

## 출력 형식

```markdown
# 바이브 코딩 실전편 N편: {주제}

**부제**: "{핵심 한 줄}" — {맥락}

---

## 들어가며

> 이전 편에서는 {요약}을 했습니다.
> 이번 편에서는 {이번 목표}를 해보겠습니다.

{동기와 배경 설명 - 1인칭 시점}

---

## Part 1: {섹션 제목}

### [작업기] {무엇을 했는지}

{상황 설명}

**Claude에게 요청:**
```
{실제 사용한 프롬프트}
```

**결과:**
{Claude가 해준 것 설명}

### [바이브 이면의 기술] {개념 설명}

> **{용어}**란?
> {비유를 통한 쉬운 설명}

{표나 비교가 필요하면 추가}

| 항목 | 설명 |
|------|------|
| ... | ... |

---

## Part 2: {다음 섹션}

### [작업기] {무엇을 했는지}

{과정 설명}

{스크린샷이 필요한 곳: [이미지 설명]}

**Claude에게 요청:**
```
{프롬프트}
```

### [바이브 이면의 기술] {개념}

{설명}

---

## 오늘의 결과물

{무엇이 완성되었는지}

- ✅ {완료 항목 1}
- ✅ {완료 항목 2}
- ⬜ {다음에 할 것}

---

## 다음 편 예고

> 다음 편에서는 **{다음 주제}**를 다룹니다.

{간단한 예고}

---

---

*바이브 코딩으로 만들었습니다. [bkamp.ai](https://bkamp.ai)*
```

## 작성 규칙

1. **대화 형식 적극 활용**
   - 실제 Claude에게 한 요청을 코드블록으로 표시
   - "Claude에게 요청:" 형식 사용

2. **이원적 구조**
   - `[작업기]`: 실제로 한 것, 경험 중심
   - `[바이브 이면의 기술]`: 비개발자를 위한 개념 설명

3. **비유 적극 사용**
   - 백엔드 = 레스토랑 주방
   - 데이터베이스 = 엑셀 시트
   - API = 주문서
   - 토큰 = 출입증

4. **어조**
   - 친근한 1인칭 (나, 제가)
   - 비개발자도 이해할 수 있게
   - 실패/시행착오도 솔직하게

5. **시각 요소**
   - 스크린샷 위치 표시: `[이미지: 설명]`
   - 표로 비교/정리
   - 체크리스트로 진행상황

## 실행 순서

1. `DEVLOG.md` 파일 읽기
2. 세션 히스토리에서 핵심 대화 추출
3. 주제별로 Part 구분
4. 각 Part마다 [작업기] + [바이브 이면의 기술] 작성
5. 비개발자 용어로 변환
6. 결과물을 `blog-draft.md`로 저장
